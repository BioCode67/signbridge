# OBS 촬영 — 시연 흐름

## OBS 설정 (5분)

| 항목 | 값 | 왜 |
|---|---|---|
| 소스 | **디스플레이 캡처** (창 캡처 아님) | 창 캡처는 브라우저 전체화면 전환 때 끊깁니다 |
| 해상도 | 1920×1080 | |
| FPS | **30** | 아바타가 30fps로 돕니다. 60은 의미 없습니다 |
| 오디오 | **데스크톱 오디오 켜기** | 앱이 소리로 답하는 장면이 핵심입니다 |
| 마이크 | 해설할 거면 켜기 | |

**웹캠은 OBS에 넣지 마세요.** 브라우저가 이미 카메라를 쓰고 있어 충돌합니다.
수어 하는 모습은 **앱 화면 안의 카메라 미리보기**로 이미 찍힙니다.

---

## 촬영 전 (반드시)

1. 사이트 열고 **5분 그대로 두기** (파일 45MB 내려받기)
2. `묻기` → **카메라 허용**
3. `묻기` → `대피소 어디?` → **위치 허용** → 지도가 뜨는지 확인
4. `대화` → 병원 → 답 카드 → **소리 나오는지 확인**
5. 브라우저 **100%** 확대(`Ctrl+0`) · `F11` 전체화면 · 알림 끄기

# 시연 흐름 — 4분 30초 · 5장면

장면마다 **끝에서 2초 가만히** 두세요. 편집할 때 자르기가 훨씬 쉬워집니다.
장면을 **따로따로 찍고 붙이는 것**을 권합니다 — 한 번에 5분을 가면 어디서
한 번 틀려도 처음부터 다시 찍어야 합니다.

| 시간 | 장면 | 어디서 | 중요도 |
|---|---|---|---|
| 0:00–0:30 | 문제 — 재난문자는 농인에게 외국어다 | 소개 페이지 `#demo` | ★ |
| 0:30–1:30 | **한국어 → 수어** | 앱 `📺 받기` | ★★ |
| 1:30–2:45 | **수어 → 한국어 → 소리** | 소개 페이지 `인식` | ★★ |
| 2:45–4:00 | **농인이 묻는 쪽이 된다 + 비행기 모드** | 앱 `📹 묻기` | ★★★ |
| 4:00–4:30 | 창구 대화 + 마무리 | 앱 `💬 대화` | ★ |

> **3분으로 줄여야 하면** 장면 1을 15초로, 장면 5를 빼세요. 2·3·4는 남기세요 —
> 그 셋이 "양방향"을 보여 주는 전부입니다.

---

## 장면 1 — 문제 (30초)

**화면**: 소개 페이지 첫 화면 → 천천히 아래로 스크롤

**말할 것**
> "재난문자는 한국어로만 옵니다. 그런데 **한국수어는 한국어와 문법이 다른
> 별개의 언어입니다.** 농인에게 재난문자는 외국어로 온 경고문입니다."

---

## 장면 2 — 한국어 → 수어 (1분) ★★

**화면**: `🤟 수어 이용자 화면` → `📺 받기`

**조작**
1. 실제 재난문자가 뜨고 아바타가 수어로 바꾸는 것을 그대로 보여 줌
2. `행동요령` 배지를 눌러 대피 요령이 수어로 나오는 것
3. `다음`으로 문장을 넘김

**말할 것**
> "문자가 오면 바로 수어로 나갑니다. 낱말 12,830개를 실제 농인 수어자 영상에서
> 뽑아 만들었습니다. **서버가 없습니다** — 전부 이 브라우저 안에서 돕니다."

**주의**: 촬영 전에 `📥 오프라인`을 `📴 준비됨`까지 받아 두세요.
안 받으면 처음 나오는 낱말에서 **아바타가 조용히 섭니다.**

---

## 장면 3 — 수어 → 한국어 → 소리 (1분 15초) ★★

**화면**: 소개 페이지 `인식` 섹션

**조작**
1. 카메라 켜기 → 손과 상반신에 **점과 선**이 찍히는 것
2. 낱말을 하나씩, **사이를 끊어서** 수어 (`머리` … 쉬고 … `아프다`)
3. 오른쪽 `확정 자막`에 낱말이 쌓임
4. **`🔊 소리로 듣기`** 클릭 → 스피커에서 한국어

**말할 것**
> "카메라는 **관절 좌표만** 뽑습니다. 영상은 이 기기 밖으로 나가지 않습니다.
> 알아들은 낱말을 한국어 문장으로 잇고 — **소리로 내보냅니다.**
> 농인이 수어로 말하면 듣는 사람은 말로 듣습니다."

**수어가 자신 없으면 — 아래 `자체수집 학습 스튜디오`를 쓰세요.**
`1) 단어 녹화`에서 낱말 하나를 고르고 `녹화`를 3번, 이걸 3개 낱말에 반복 →
`2) 학습 & 적용` → 그다음부터 **내 손동작을 알아봅니다.**
이건 **누가 해도 됩니다.** 다만 이렇게 말하세요:
> "지금 이건 브라우저 안에서 즉석으로 배운 겁니다. 배포한 모델은 **13,576개**를
> 압니다 — 처음 보는 수어자 13명에서 78.6%였습니다."

---

## 장면 4 — 농인이 묻는 쪽이 된다 (1분 15초) ★★★

**화면**: 앱 `📹 묻기`

**조작**
1. 가운데 📹 버튼 → 카메라
2. 수어: `대피` … `어디` — **또는 화면의 `🏫 대피소 어디?` 버튼을 그냥 누르기**
3. 답이 나옴 — **방향 · 거리 · 걸리는 시간 · 지도 · 아바타 수어**
4. **여기서 비행기 모드 켜기** → `📹 또 묻기` → **똑같이 답함**

**말할 것**
> "지금까지 이 앱에서 농인은 정보를 **받기만** 했습니다.
> '대피소 어디예요?'는 들리는 사람이면 지나가는 사람에게 물어 3초에 끝납니다.
> 농인에게는 그 3초가 통째로 막혀 있습니다."

> (비행기 모드를 켜 보이며) "**지도 타일을 쓰지 않습니다.**
> 재난 때가 곧 오프라인입니다."

**안 되면**: 못 알아들어도 화면이 알아들은 낱말과 예시 버튼을 보여 줍니다.
그걸 눌러 진행하세요 — 흐름이 안 끊깁니다.

---

## 장면 5 — 창구 대화 + 마무리 (30초)

**화면**: 앱 `💬 대화` → `🏥 병원`

**조작**
1. 직원이 말하면 → 자막 + 수어
2. 농인이 답 카드를 누르면 → **소리로 출력**

**마지막에 이 한 줄로 끝내세요.**
> "**한쪽만 되면 방송이고, 양쪽이 되어야 대화입니다.**"

## 질문이 나오면 (2026-08-19에 재어 둔 답)

**"이어서 수어하면 왜 못 알아듣나요?"**
> 연속 문장 인식 모델은 **이미 학습을 끝냈습니다**(검증 WER 0.218).
> 그런데 앱에 아직 안 붙였습니다. 그 모델은 낱말을 8,147종 아는데 지금 붙어 있는
> 모델은 13,576종을 압니다. 바꿔 끼우면 `화장실`이 사라져서 **화장실을 물으면
> 영영 못 알아듣게 됩니다 — 오류도 안 나고요.** 두 개를 같이 돌리면 풀리지만,
> 그게 정말 나은지는 농인이 이어서 한 수어를 받아 봐야 압니다. 9월에 잽니다.

**"농인의 답을 한국어로 바꾸는 건 AI인가요?"**
> 거기만 **규칙**입니다. 학습 모델도 만들어 재봤습니다 — 재난문자에서는 사람
> 번역과 글자까지 같은 문장이 나올 정도였습니다(음절 BLEU 69.7). 그런데 일상어를
> 넣으면 "머리 아프다"를 **"오늘 아침 기온이 크게 오르고 있습니다"** 로 바꿉니다.
> 재난 말뭉치로만 배웠으니까요. 이건 **직원이 소리로 듣는 문장**이고 농인은 자기
> 말이 어떻게 나갔는지 볼 수 없습니다. 그래서 안 붙였습니다. 뻣뻣해도 안 틀리는
> 쪽을 씁니다.

**"정확도 78%면 낮지 않나요?"**
> 13,576개 중에 고르는 문제입니다. 그리고 **처음 보는 수어자 13명**에서 78.6%가
> 나왔습니다 — 검증 숫자와 같습니다. 같은 사람이 학습과 평가에 섞이면 숫자가
> 부풀기 때문에 수어자를 분리해 쟀습니다.

**"이 숫자들 믿을 수 있나요?"**
> 저장소의 검사 스크립트가 전부 다시 계산해 냅니다. 자동 검사 259개가 매번 돕니다.

**말하지 말 것** — 재지 않은 것. "농인이 써 보니 좋다더라"(9월에 잽니다),
"실시간 문장 번역"(낱말 단위입니다), "공식 대피소"(OSM 참고용입니다).
