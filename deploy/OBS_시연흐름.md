# OBS 촬영 — 시연 흐름

## OBS 설정 (5분)

| 항목 | 값 | 왜 |
|---|---|---|
| 소스 | **디스플레이 캡처** (창 캡처 아님) | 창 캡처는 브라우저 전체화면 전환 때 끊깁니다 |
| 해상도 | 1920×1080 | |
| FPS | **30** | 아바타가 30fps로 돕니다. 60은 의미 없습니다 |
| 오디오 | **데스크톱 오디오 켜기** | 앱이 소리로 답하는 장면이 핵심입니다 |
| 마이크 | 해설할 거면 켜기 | |

**웹캠은 OBS에 넣지 마세요.** 브라우저가 이미 카메라를 쓰고 있어 충돌합니다.
수어 하는 모습은 **앱 화면 안의 카메라 미리보기**로 이미 찍힙니다.

---

## 촬영 전 (반드시)

1. 사이트 열고 **5분 그대로 두기** (파일 45MB 내려받기)
2. `묻기` → **카메라 허용**
3. `묻기` → `대피소 어디?` → **위치 허용** → 지도가 뜨는지 확인
4. `대화` → 병원 → 답 카드 → **소리 나오는지 확인**
5. 브라우저 **100%** 확대(`Ctrl+0`) · `F11` 전체화면 · 알림 끄기

# 시연 흐름 (5분 · 5장면)

각 장면 끝에 **2초 정지**. 편집이 쉬워집니다.

---

## 장면 1 — 문제 (30초)

**화면**: 랜딩 첫 화면

**말할 것**
> "국내 청각장애인이 44만 명입니다. 재난문자는 전부 한국어 텍스트입니다.
> 그런데 **한국수어는 한국어와 문법이 다른 별개의 언어**입니다.
> 자막이 있어도 못 읽는 분들이 있습니다."

**조작**: 스크롤 → `실측 성과` 섹션에서 잠깐 멈춤

---

## 장면 2 — 핵심 기술 ①: 수어 → 한국어 → 소리 (1분 30초) ★★

**화면**: 상단 메뉴 `인식`

**조작**
1. **카메라 시작** → 손·상반신에 점과 선이 찍히는 것을 보여줌
2. 오른쪽 패널의 ①②③ 흐름을 손가락으로 짚어 줌
3. 수어: `머리` … (1초 쉬고) … `아프다`
4. 낱말이 쌓이면 → **🔊 소리로 듣기** 클릭

**말할 것**
> "카메라가 관절 좌표만 뽑습니다. 영상은 이 기기 밖으로 나가지 않습니다.
> 알아들은 낱말을 한국어 문장으로 잇고 — **소리로 내보냅니다.**
> 농인이 수어로 말하면 듣는 사람은 말로 듣습니다."

**주의**
- **낱말 하나씩, 사이를 끊어서.** 이어서 하면 아직 못 읽습니다
- 손을 화면 가운데, 크게
- 엉뚱한 낱말이 뜨면 `자막 지우기` 후 다시 (정상입니다 — 첫 후보 74%)

---

## 장면 3 — 핵심 기술 ②: 한국어 → 수어 (1분)

**화면**: 앱 `받기` (오른쪽 위 금색 **수어 이용자 화면**)

**조작**
1. 아바타가 이미 재난문자를 수어로 하고 있음 → **자막의 낱말이 하나씩 켜지는 것**을 짚어 줌
2. `📋 행동요령` → 문장 하나 클릭

**말할 것**
> "반대 방향입니다. 재난문자가 들어오면 글로스로 번역하고,
> 실제 농인 수어자를 찍은 동작 12,833개를 이어 붙여 아바타가 수어를 합니다."

> "행동요령은 **일부러 사전으로** 번역합니다. 학습 모델로 보냈더니
> '엘리베이터를 타지 말고 계단으로 대피하세요'가 엉뚱한 수어로 나갔습니다.
> 목숨이 걸린 안내라 덜 틀리는 쪽을 씁니다."

---

## 장면 4 — 농인이 묻는 쪽이 된다 (1분 30초) ★★★

**화면**: 앱 `📹 묻기`

**조작**
1. 가운데 큰 버튼 → 카메라
2. 수어: `대피` … `어디`
3. 답이 나옴 → **방향 · 거리 · 지도 · 아바타 수어**
4. **여기서 비행기 모드 켜기** → `또 묻기` → 다시 답이 나옴

**말할 것**
> "지금까지 이 앱에서 농인은 정보를 **받기만** 했습니다.
> '대피소 어디예요?'는 들리는 사람이면 지나가는 사람에게 물어 3초에 끝냅니다.
> 농인에게는 그 3초가 통째로 막혀 있습니다."

> (비행기 모드 켜고) "지도 타일을 쓰지 않습니다. **재난 때가 곧 오프라인입니다.**"

**안 되면**: 못 알아들으면 화면이 알아들은 낱말과 예시 버튼을 보여줍니다.
그 버튼을 눌러 진행하세요 — 흐름이 안 끊깁니다.

---

## 장면 5 — 창구 대화 (1분)

**화면**: 앱 `💬 대화` → 🏥 병원 → 화면 한 번 누르기

**조작**
1. `직원 질문 카드` → "어디가 아픈가요?" → 아바타가 수어로
2. `내 답 카드` → `머리` → **소리로 나감**
3. (여유되면) `🤟 수어로 답하기` → 수어로 답 → 소리

**말할 것**
> "직원은 말하고 농인은 수어로 봅니다. 농인이 답하면 직원은 소리로 듣습니다.
> **양쪽 다 자기 언어를 씁니다.**"
> "키오스크로 세우면 5분 뒤 앞사람 대화가 자동으로 지워집니다."

**"정확도가 얼마나 되나요?"**
> 낱말 인식 top-1 78.2%입니다. 13,576개 중에서 고르는 문제이고,
> **학습에 안 쓴 수어자**로 재도 78.6%가 나옵니다.

**"서버는 어디 있나요?"**
> 없습니다. 인식·번역·아바타가 전부 브라우저 안에서 돕니다.
> 그래서 비행기 모드에서도 되고 영상이 기기 밖으로 안 나갑니다.

**"뭐가 아직 안 되나요?"** ← 정직하게 답하는 것이 신뢰를 만듭니다

> ② **표정** — 눈썹 방향이 원본에 없어 지어내지 않았습니다.
