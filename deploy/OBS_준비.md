# OBS 준비 — 설정부터 테스트 녹화까지 (20분)

촬영 흐름은 `OBS_시연흐름.md`에 있습니다. 이 문서는 **OBS를 어떻게 세팅하는가**만
다룹니다. 위에서부터 순서대로 하시면 됩니다.

---

## 1. 설정 → 출력  (가장 중요)

**출력 모드를 `고급`으로 바꾸세요.** 기본 모드는 손댈 게 없습니다.

| 항목 | 값 | 왜 |
|---|---|---|
| 녹화 형식 | **mkv** | mp4로 찍다가 OBS가 죽으면 **파일이 통째로 날아갑니다.** mkv는 살아남습니다 |
| 인코더 | NVIDIA NVENC (있으면) · 없으면 x264 | 노트북 발열·끊김이 줄어듭니다 |
| 속도 제어 | CQP (x264는 CRF) | |
| CQ / CRF | **18** | 숫자가 낮을수록 고화질. 18이면 화면 글씨가 또렷합니다 |
| 프리셋 | Quality | |

> 촬영이 끝나면 OBS 메뉴 **파일 → 녹화 다시 포장**으로 mkv를 mp4로 바꿉니다.
> 다시 인코딩하지 않아 화질 손실이 없고 몇 초면 끝납니다.

## 2. 설정 → 비디오

| 항목 | 값 |
|---|---|
| 기본(캔버스) 해상도 | **1920×1080** |
| 출력(조정된) 해상도 | **1920×1080** — 같게 두세요 |
| FPS | **30** |

60fps는 필요 없습니다. 아바타는 30fps로 재생되고, 파일만 두 배가 됩니다.

## 3. 설정 → 오디오

- **데스크톱 오디오: 기본값** ← 이게 꺼져 있으면 앱이 소리로 답하는 장면이
  **무음으로 녹화됩니다.** 이 시연의 핵심 장면입니다.
- 마이크: 내레이션 할 거면 켜고, 나중에 목소리를 따로 입힐 거면 꺼 두세요.

> 고급 오디오 속성에서 데스크톱 오디오와 마이크를 **다른 트랙**으로 보내면
> 편집할 때 목소리만 따로 키울 수 있습니다. (출력 → 녹화 → 오디오 트랙 1,2 체크)

## 4. 소스 추가

**`디스플레이 캡처` 하나만 넣으세요.**

- ❌ `창 캡처`를 쓰면 브라우저를 **전체화면(F11)으로 바꾸는 순간 검게** 나옵니다
- ❌ **웹캠(비디오 캡처 장치)을 OBS에 넣지 마세요.** 브라우저가 이미 카메라를
  잡고 있어서 둘 중 하나가 안 켜집니다. 카메라 화면은 **앱 안에 이미 나옵니다**

커서를 보여 주려면 디스플레이 캡처 속성에서 `커서 캡처` 체크.

---

## 5. 녹화 전 점검 (5분)

- [ ] 브라우저 확대 **100%** (`Ctrl+0` / `⌘+0`)
- [ ] 알림 끄기 — 윈도우 `Win+A` → 집중 지원 / 맥은 방해금지 모드
- [ ] 메신저·메일 종료 (팝업이 화면에 찍힙니다)
- [ ] 배터리 절전 모드 끄기 (프레임이 떨어집니다)
- [ ] 사이트를 열고 **5분 그냥 두기** — 파일 15MB + 모델 30MB를 미리 받습니다
- [ ] `묻기` → 카메라 **허용**, `대피소 어디?` → 위치 **허용**
- [ ] `대화` → 🏥 병원 → 답 카드 하나 눌러 **스피커에서 소리 확인**

## 6. 1분 테스트 녹화 — 건너뛰지 마세요

짧게 찍고 **바로 재생해서** 확인합니다.

1. 소리가 들어갔는가 ← 가장 자주 빠집니다
2. 글씨가 읽히는가
3. 끊김이 없는가
4. 알림 팝업이 안 찍혔는가

여기서 안 되는 건 본 촬영에서도 안 됩니다.

---

## 자주 나는 문제

| 증상 | 원인 |
|---|---|
| 화면이 검게만 나옴 | `창 캡처`를 씀 → `디스플레이 캡처`로 바꾸기 |
| 앱 소리가 안 들어감 | 설정 → 오디오 → 데스크톱 오디오가 `사용 안 함` |
| 카메라가 안 켜짐 | OBS가 웹캠을 잡고 있음 → OBS에서 웹캠 소스 삭제 |
| 카메라가 안 켜짐 (2) | 주소가 `localhost`가 아님. `192.168.x.x`는 브라우저가 막습니다 |
| 아바타가 중간에 멈춤 | 파일을 다 안 받은 상태 → 5분 미리 열어 두기 |
| 위치를 못 잡음 | 실내 GPS 문제. 와이파이를 켜 두거나 창가에서 한 번 잡기 |
| 영상이 끊김 | 인코더가 x264 + 프리셋이 높음 → NVENC로 바꾸거나 프리셋 낮추기 |
