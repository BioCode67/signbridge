SignBridge — 노트북에서 바로 보기
=====================================

■ 여는 방법  (인터넷 없어도 됩니다)

  윈도우 :  시작하기_윈도우.bat  을 더블클릭
  맥     :  시작하기_맥.command  을 더블클릭
            (처음엔 "확인되지 않은 개발자" 경고가 뜰 수 있습니다.
             파일을 우클릭 -> 열기 -> 열기 를 누르면 됩니다)

  브라우저가 자동으로 열립니다.
  안 열리면 주소창에 직접 :  http://localhost:8000

  ※ 검은 창을 닫으면 사이트도 닫힙니다. 시연 끝날 때까지 두세요.
  ※ 파이썬이 없어도 됩니다. 없으면 윈도우에 기본으로 있는
     PowerShell 로 알아서 시작합니다.


■ 그래도 안 열릴 때

  1) 검은 창에 뭐라고 쓰여 있는지 보세요.
  2) 브라우저 주소창에 직접 http://localhost:8000 을 쳐 보세요.
  3) 그래도 안 되면 서버.ps1 을 우클릭 -> "PowerShell에서 실행"
  4) "포트 8000 을 못 씁니다" 가 나오면 이미 켜져 있는 것입니다.
     브라우저에서 http://localhost:8000 으로 바로 들어가면 됩니다.


■ 열고 나서 할 것  (촬영 전 5분)

  1) 오른쪽 위 금색 [수어 이용자 화면] 클릭
  2) 맨 윗줄 오른쪽 [오프라인 124.4MB] 클릭
     -> [준비됨] 초록색이 될 때까지 기다리기
  3) [묻기] 탭 -> 카메라 허용 -> [대피소 어디?] -> 위치 허용
  4) [대화] 탭 -> 병원 -> 답 카드 눌러 소리 확인


■ 보여줄 순서  (4분 30초)

  0:00  소개 페이지        문제 제기
  0:30  받기               재난문자가 수어로
  1:30  인식               수어가 한국어와 소리로
  2:45  묻기               농인이 묻는다 + 비행기 모드
  4:00  대화               창구 대화

  자세한 대본은 script.html 을 여세요.
