## 장면 1 — 개요 + 실시간 재난문자 관제 (0:00 ~ 0:55)

**화면**: 히어로 3초 → 수어 데모 섹션 → [▶ 실시간 재난문자 수신] → 2건 처리

**멘트**:
"팀 닿다의 SignBridge입니다. 국내 청각장애인 42만 명에게 한국수어는 모어이고
한국어는 제2언어인데, 재난문자는 텍스트로만 옵니다. 저희는 재난 정보를 수어로,
수어를 한국어로 바꾸는 양방향 AI를 AI Hub 실데이터 40만 클립으로 직접 학습했습니다.
지금 실제 재난문자가 수신-번역-합성-송출되고 있습니다. 화면의 처리 시간은 전부
브라우저 실측값이고, 송출은 영상이 아니라 관절좌표라 문장당 2.4킬로바이트입니다."

## 장면 2 — 병원 창구 대화 (0:55 ~ 2:30) ★ 핵심 장면

**화면**: [🤟 수어 이용자 화면] → [💬 대화] → 🏥 병원

**조작 순서**
1. **[🎙 직원이 말하기]** 누르고 마이크에 육성으로:
   "어디가 아프신지 말씀해 주세요" → 자막이 뜨고 아바타가 수어로 표현
2. **[🤟 내 답 카드]** → "머리" 짚기 → 화면에 크게 뜨고 **스피커에서 "머리" 소리**
3. **[⌨ 글로 쓰기]** → "어제부터 머리가 아파요" → [🔊 소리로 말하기]
4. **[🤟 수어로 답하기]** → 카메라 앞에서 수어 한두 낱말 → [🔊 전하기]

**멘트**:
"실제로 쓰이는 자리를 보여드리겠습니다. 병원 창구입니다.
직원이 마이크를 누르고 평소처럼 말하면, 준비된 문장이 아니라 **지금 처음 하는 말**이
자막과 수어로 동시에 전달됩니다. 반대 방향이 중요합니다 — 농인이 답을 짚으면
**소리로 나갑니다.** 택시 기사는 운전 중 화면을 볼 수 없고, 병원 직원은 등을 돌리고
차트를 봅니다. 소리로 나가야 대화가 왕복합니다.
소리를 못 듣는 분은 소리가 나갔는지 확인할 수 없으니, 전달됐다는 사실을 화면으로
알려 드리고, 합성이 실패하면 실패했다고 붉게 알립니다.
카드에 없는 말은 직접 쓰면 읽어 주고, **수어로 답하면 그대로 소리가 됩니다** —
카드도 한글도 거치지 않는, 모어로 말하는 길입니다."

## 장면 3 — 수어 인식과 안전장치 (2:30 ~ 3:35)

**화면**: [🤟 말하기] → 카메라 → 수어 동작 → 인식 자막(후보 % 표시) → [문장으로 보기]

**멘트**:
"인식 쪽입니다. 8,147개 수어 단어를 브라우저 안에서 18밀리초에 인식하고, 영상은
어디로도 전송되지 않습니다. 정확도는 수어자 분리 기준 78.7%, 학습에 전혀 없던
수어자 13명으로도 78.6%, 상위 5개 안에 들 확률은 91.9%입니다. 수어자가 바뀌어도
성능이 그대로라는 뜻입니다. 핵심 안전장치가 있습니다 — AI가 복원한 문장을
역번역해 원래 수어와 대조하는 왕복 자체검증입니다. 뜻이 어긋나면 자동으로 저신뢰가
붙고 원문 수어를 앞세웁니다. 안전 안내에서는 그럴듯한 오역이 가장 위험하기 때문입니다."

창구 상용구와 고빈도 어휘를 첫 방문 뒤 조용히 내려받고, 전체는 사용자가 눌러
받습니다. 지금 네트워크를 완전히 끊었는데도 그대로 동작합니다. 홈 화면에 설치되는

|---|---|
| 정확도 78%면 낮지 않나 | 8,147클래스 분류 · **처음 보는 수어자에서도 78.6%**(검증 78.7%와 같다 = 수어자에 과적합되지 않았다) · top-5 91.9%. 인식 낱말을 후보에서 골라 고칠 수 있어 실사용 정확도는 top-5에 가깝다 |

| 손말잇기 팀과 뭐가 다른가 | 실데이터 40만 클립 직접 학습 · 정확도/커버리지/지연 전부 실측 공개 · 브라우저 단독+오프라인 · 오역 자동감지 · **창구 왕복 대화(음성 출력·수어 입력)** 까지 완성 |
| 아바타 수어를 농인이 이해하나 | 실제 농인 수어자의 실연 동작 그대로 사용. 비수지(표정) 통합·당사자 평가가 다음 단계 |
| KOREN을 실제로 썼나 | 학습 전 과정이 KOREN AI Cloud H200(실데이터 133GB). HPC 분산 전처리 잡·VM 상시 서버는 스크립트까지 준비 완료 |

| 지문자(고유명사)는 | 공개 데이터에 지문자 세트가 없어 동작 표현 불가 — 낱말 카드로 정보 손실을 막고, 데이터 확보 시 통합 |
