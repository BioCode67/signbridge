## 1. 앱이 "재난문자 뷰어"에서 "창구 대화 도구"가 됐습니다

이전에는 직원이 **미리 준비된 카드만** 누를 수 있었고, 농인의 답은 **화면으로만** 나갔습니다.
현장은 그렇지 않습니다 — 의사는 카드에 없는 말을 하고, 택시 기사는 운전 중 화면을 못 봅니다.

| 방향 | 이전 | 지금 |
|---|---|---|
| 직원 → 농인 | 준비된 카드 30개 | **마이크로 자유롭게 말하면** 자막 + 수어 아바타 |
| 농인 → 직원 | 화면에 크게 | **소리로 나갑니다**(기기 내장 음성합성, 서버·요금 불필요) |
| 농인 입력 | 카드 짚기 | 카드 · **글로 쓰기** · **수어로 답하기**(카메라 → 한국어 문장 → 소리) |
| 창구 | 5곳 | **10곳 59문구**(병원·약국·주민센터·택시·긴급·은행·식당·경찰서·우체국·마트) |

그 밖에 넣은 것

- **직원 안내 화면** — 장소를 고르면 먼저 뜹니다. "저는 소리를 듣지 못합니다 / 파란 버튼을
  누르고 평소처럼 말씀해 주세요". 창구에서 가장 먼저 필요한 건 번역이 아니라 사용법입니다.
- **내 정보**(혈액형·지병·약·알레르기·보호자 연락처) — 응급 화면에 크게 뜹니다.
  의식이 흐리거나 손을 다쳐 수어를 못 할 때, 카드가 떠 있기만 해도 조치가 됩니다.
  적어 둔 주소·보호자 연락처는 **답 카드로도** 나옵니다(택시에서 주소를 바로).
- **내 위치 좌표** — SOS 화면에서 119에 읽어 줄 수 있게.
- **지난 대화 보관** — "3일 뒤에 다시 오세요"처럼 잊기 쉬운 말을 나중에 다시 봅니다.
  **저장은 누를 때만** 합니다(공용 기기에 앞사람 진료 내용이 남으면 안 되므로).
- **오프라인** — 첫 방문 뒤 필수 11MB를 조용히 받아 둡니다. **회선을 완전히 끊고도
  창구 대화가 되는 것을 자동 검증**에 넣었습니다.
- **키오스크 모드** `#/app?kiosk=1` — 대화 화면 시작·큰 글씨·닫기 숨김·5분 자동 초기화.
- **아이폰 설치 안내** — 사파리에는 설치 버튼이 없어 아이폰 사용자는 설치 가능한지도
  몰랐습니다.

## 2. 번역 품질 — 도메인마다 재고 올렸습니다

| 무엇 | 아침 | 지금 |
|---|---|---|
| 재난문자 246건 | 93.7% | **95.8%** |
| 재난 행동요령 38문장 | 80.8% | **100.0%** |
| 창구 대화 58문장 | 64.9% | **85.7%** |
| 창구 대화 **홀드아웃** 37문장 | — | **81.9%** |

홀드아웃은 **고칠 때 보지 않은 문장**입니다. 시험 문장에만 맞춘 것이 아니라는 증거로
따로 만들었습니다(`scripts/audit_sets/`).

주요 원인과 조치

1. **활용형** — 기다려·찍어·오셨나요·아프신가요·될까요가 통째로 빠졌습니다.
   빌드 시점에 활용형을 펼쳐 사전 키로 넣었습니다(런타임은 한 줄도 안 고쳤습니다).
2. **일상어가 잘려 있었음** — 웹 동작 사전이 재난문자 빈도로 뽑혀,
   결과·수술·도장·요금·안전벨트가 **표현할 수 있는데 실리지 않았습니다.** 전량 편입.
3. **날짜·시각 주석 오염** — `날짜:9월16일` 같은 클립이 낱말 **2만 개**의 1순위였습니다
   (주택→날짜:9월16일). 번역·웹 사전에서 제외.
4. **수어 어순** — 말뭉치 20만 문장에서 낱말 위치를 재어 `[언제·어디] → [무슨 일] →
   [당부]` 순서로 재배치합니다. "조심하세요 오늘 경산시에 지진" → **경산 오늘 지진 조심**.
5. **행동요령은 문장을 다시 썼습니다** — 뜻은 그대로, 낱말만 표현 가능한 것으로
   (차단→잠그다, 탁자→가구, 빙판길→얼음길). 그래서 100%입니다.

## 3. 인식 모델

- **iso-v1 완료** — 검증 top-1 **0.7868**, 학습에 전혀 없던 수어자 13명(49,721표본)으로도

- 앱에 붙어 있던 **에폭 27짜리(0.7746)** 모델을 최종본으로 교체했습니다.
- **iso-v2 학습 중** — 재난+일상 합본(클래스 8,147 → **13,576**, 표본 217만).
  끝나면 창구 낱말(가슴·열·기침·얼마·화장실)이 인식됩니다. 그 뒤 CTC(연속 문장)로 이어집니다.
- 인식이 틀렸을 때 **후보에서 골라 고칠 수 있게** 했습니다 — top-1 78.7%를 손가락
  한 번으로 top-5 91.9%로 쓰는 셈입니다.

## 4. 눈으로는 못 잡는 것들을 잡았습니다

- **아바타가 서 있는데 화면은 정상처럼 보이던 문제** — 동작 사전을 다시 만들자 상용구
  30개 중 17개의 글로스가 사라졌습니다. 이제 `check_app_glosses.py`가 막습니다.
- **느린 기기에서 수어가 슬로모션** — 재생 루프가 화면 한 틱에 한 프레임씩만 넘겨,
  20초짜리가 5분이 됐습니다. 수어는 속도가 뜻의 일부라 **정확성 문제**입니다.
- **3단 폴백이 코드에선 2단** — 서버가 없으면 사전을 건너뛰고 규칙으로 떨어져
  재생 불가능한 글로스를 내놓고 있었습니다.
- **창구 반응 2.1초 → 0.52초** — 장소에 들어설 때 그 창구의 동작 조각을 미리 받아 둡니다.

검사 도구도 함께 남겼습니다.

