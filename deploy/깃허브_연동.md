# 깃허브에 계속 저장하며 작업하기

## 지금 상태

원격은 **이미 연결돼 있습니다.**

    origin  https://github.com/BioCode67/signbridge.git

커밋도 계속 쌓이고 있습니다(로컬 362개). 다만 **인증 수단이 없어 올라가지 못하고
274개가 밀려 있습니다.** 읽기(`git ls-remote`)는 되고 쓰기만 막혀 있습니다.

## 필요한 것 — 토큰 하나 (3분)

### 1. 토큰 만들기

github.com 로그인 → 오른쪽 위 사진 → **Settings** → 맨 아래 **Developer settings**
→ **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**

- **Note**: `signbridge-koren` (아무 이름이나)
- **Expiration**: 90 days 정도
- **권한**: **`repo`** 하나만 체크 (그 아래 항목들이 자동으로 함께 체크됩니다)

**Generate token** → 화면에 뜨는 `ghp_...` 문자열을 복사하세요.
**이 화면을 벗어나면 다시 못 봅니다.**

### 2. 이 워크스페이스에 넣기

터미널에 아래를 입력하세요. **`ghp_...` 자리에 복사한 토큰을 넣습니다.**

```bash
export GH_TOKEN=ghp_여기에붙여넣기
bash deploy/푸시하기.sh
```

`푸시하기.sh`는 토큰을 **한 번만 쓰고 파일이나 주소에 남기지 않습니다.**
화면 출력에서도 가립니다.

### 3. 그다음부터

Claude Code에게 "푸시해줘"라고 하면 됩니다. 또는 커밋할 때마다 자동으로 올리게
하려면 아래를 한 번 실행하세요(토큰을 저장합니다).

```bash
git config --global credential.helper store
GIT_ASKPASS=true git push origin HEAD    # 한 번 물어보면 사용자명 BioCode67, 비밀번호는 토큰
```

> ⚠️ `credential.helper store`는 토큰을 **평문으로** `~/.git-credentials`에 남깁니다.
> 이 워크스페이스는 본인만 쓰므로 괜찮지만, 공용 장비라면 쓰지 마세요.

## 작업 공간 셋도 함께 올라갑니다

`work/sign`·`work/avatar`·`work/ui` 가지도 같은 저장소에 올라갑니다.

```bash
git push origin work/sign work/avatar work/ui
```

각 터미널에서 따로 올려도 되고, `app`에서 한 번에 올려도 됩니다.
**가지가 나뉘어 있어 서로 덮어쓰지 않습니다.**

## 토큰 없이 버티는 법 (지금까지 하던 것)

토큰을 못 만드는 상황이면 **번들**로 옮깁니다.

```bash
bash deploy/번들만들기.sh          # ~/deploy/signbridge-full.bundle
```

파일 하나에 커밋 전부가 들어 있습니다. 노트북으로 내려받아:

```bash
git clone signbridge-full.bundle signbridge
cd signbridge
git remote set-url origin https://github.com/BioCode67/signbridge.git
git push origin --all
```

번들은 **인터넷 없이도** 옮길 수 있어, 워크스페이스가 사라져도 작업이 남습니다.

## 무엇이 기록되나

- **커밋 메시지** — 무엇을 왜 고쳤는지 한 줄
- **`DECISIONS.md`** — 판단이 필요했던 결정과 근거(측정값 포함)
- **`CLAUDE.md`** — 현재 상태·수치·함정. 새 세션이 이것만 읽고 이어받습니다

세 가지가 함께 올라가므로, 나중에 "왜 이렇게 했지"를 되짚을 수 있습니다.
