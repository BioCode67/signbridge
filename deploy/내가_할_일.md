# 내가 할 일 (딱 세 가지)

## 1. 작업물 안전하게 챙기기 — 5분, 오늘 밤

워크스페이스 파일 브라우저에서 **두 파일만** 내려받으세요.

| 파일 | 크기 | 무엇 |
|---|---|---|
| `~/deploy/signbridge-full.bundle` | 268MB | **코드 전부**(커밋 360개). 이거면 어디서든 복원됩니다 |
| `~/deploy/signbridge-노트북용.zip` | 188MB | **사이트 그 자체**. 풀어서 더블클릭하면 열립니다 |

> 번들 복원은 나중에 이렇게 합니다:
> `git clone signbridge-full.bundle signbridge`

## 2. 내일 사이트 보여주기 — 준비 3분

압축을 풀고 **더블클릭**만 하면 됩니다.

- 윈도우 → `시작하기_윈도우.bat`
- 맥 → `시작하기_맥.command`

브라우저가 열립니다(`http://localhost:8000`).
**인터넷이 없어도 됩니다.** 와이파이가 바뀌어도, 아예 없어도 그대로 돕니다.

> 검은 창을 닫으면 사이트도 닫힙니다. 시연 끝날 때까지 두세요.
> 파이썬이 없다고 나오면 python.org에서 설치(윈도우는 "Add Python to PATH" 체크).

**전날 밤에 한 번 열어 보세요.** 처음 열 때 파일을 받아 두면 다음부터 즉시 뜹니다.

## 3. GitHub에 올리기 — 2분 (택 1)

### A. 토큰을 주시면 제가 올립니다 (가장 빠름)

1. github.com → 프로필 → **Settings** → 맨 아래 **Developer settings**
2. **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**
3. Note에 `signbridge`, Expiration `7 days`, 체크는 **repo** 하나만
4. **Generate token** → `ghp_` 로 시작하는 문자열 복사 → 저에게 주세요

토큰은 한 번 쓰고 버립니다. 파일에도 원격 주소에도 남기지 않습니다.

### B. 직접 올리기

번들을 내려받은 뒤 노트북에서:

```bash
git clone signbridge-full.bundle signbridge
cd signbridge
git remote set-url origin https://github.com/BioCode67/signbridge.git
git push origin claude/sign-language-translation-system-a0mzqi
```
