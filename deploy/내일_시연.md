# 내일 시연 — 사이트 주소 만들기

**결론부터.** 이 앱은 서버가 필요 없습니다. 파일만 올리면 주소가 생깁니다.
아래 A안이 가장 빠릅니다(10~20분, 대부분 업로드 기다리는 시간).

지금 쓰는 무료 터널은 **60분마다 주소가 바뀌고 이 워크스페이스가 꺼지면 같이
죽습니다.** 사람들 앞에서 쓰면 안 됩니다.

---

## 0. 먼저 파일 내려받기 (공통)

워크스페이스 파일 브라우저에서 아래 파일을 내려받으세요.

```
~/deploy/signbridge-site.zip      ← 이것 하나 (167MB · 낱말 12,830개 전부)
```

> **가벼운 판은 만들지 않습니다.** 자주 쓰는 낱말만 남긴 93MB 판을 만들어 돌려
> 봤더니, 화면에는 "북서쪽 350미터 대피하세요"가 뜨는데 **아바타는 가만히 서
> 있었습니다**(프레임 1 · 글로스 0). 없는 낱말은 오류 없이 조용히 건너뜁니다.
> 업로드 74MB를 아끼려다 시연 도중 수어가 안 나오는 쪽이 훨씬 비쌉니다.

내려받은 zip을 **풀어 두세요.** 폴더 안에 `index.html`이 바로 보여야 합니다.

## A안 — Netlify Drop (가장 빠름)

1. https://app.netlify.com/drop 에 접속
2. GitHub 계정으로 로그인 (한 번 클릭)
3. 압축을 푼 **폴더를 통째로 끌어다 놓기**
4. 끝. `https://무작위이름.netlify.app` 주소가 바로 나옵니다

주소를 바꾸고 싶으면 Site settings → Change site name.

> 무료 대역폭이 월 100GB입니다. 시연 몇 번은 충분합니다.

---

## B안 — Cloudflare Pages (대역폭 제한 없음)

오래 쓸 거면 이쪽이 낫습니다.

1. https://dash.cloudflare.com 가입 (무료)
2. 왼쪽 **Workers & Pages** → **Create** → **Pages** → **Upload assets**
3. 프로젝트 이름 적고, 압축 푼 **폴더를 끌어다 놓기**
4. Deploy → `https://이름.pages.dev` 주소가 나옵니다

---

## C안 — 인터넷 없이 노트북에서 (마지막 보루)

행사장 인터넷이 못 미더우면 이게 가장 안전합니다.
압축 푼 폴더에서 터미널을 열고:

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` — 끝입니다.
**인터넷이 아예 없어도 됩니다.** 카메라 인식·아바타·번역이 전부 브라우저 안에서 돕니다.

> 다만 `localhost`가 아닌 주소(다른 기기에서 접속)로는 카메라가 안 켜집니다.
> 브라우저가 HTTPS를 요구하기 때문입니다. 노트북 한 대로 보여줄 때 쓰세요.

## 보여줄 화면 순서 (5분)

주소를 열면 `#/app`으로 바로 들어갑니다. 탭 네 개가 전부입니다.

| 탭 | 무엇을 보여주나 | 한마디 |
|---|---|---|
| 📺 **받기** | 재난문자가 수어로 나온다 | "지금 이 문자를 농인은 못 읽습니다" |
| 📹 **묻기** | 카메라 앞에서 수어 → 위치로 답 | "농인이 처음으로 **묻는** 쪽이 됩니다" |
| 💬 **대화** | 직원 말 → 수어, 농인 답 → 소리 | 병원·주민센터 창구 |
| 📖 **사전** | 낱말을 찾아 수어로 확인 | 12,833개 |

- 키오스크 모드는 주소 뒤에 `?kiosk=1`을 붙입니다 (`.../#/app?kiosk=1`).
- **카메라·마이크는 HTTPS에서만** 켜집니다. A·B안은 자동으로 HTTPS입니다.
- 처음 열 때 필수 파일(15MB)을 조용히 받아 둡니다. 미리 한 번 열어 두세요.

---

## 미리 확인할 것 (행사 전날 밤 3분)

1. 주소를 폰으로 열어 **받기** 탭에서 아바타가 움직이는지
2. **묻기** 탭에서 카메라 권한을 한 번 허용해 두기
3. **대화** 탭 → 병원 → 질문 카드 하나 눌러 수어가 나오는지
4. 비행기 모드로 바꾸고 다시 열어 보기 (오프라인에서도 열립니다)
