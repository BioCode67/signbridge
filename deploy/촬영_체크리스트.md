# 시연 영상 촬영 — 내가 할 일

순서대로만 하시면 됩니다. **위 세 개가 안 되면 촬영이 무너집니다.**

---

## ★★★ 반드시 (촬영 30분 전)

### 1. 사이트 열어 두기 — 5분

압축 푼 폴더에서 `시작하기_윈도우.bat`(맥은 `.command`) 더블클릭
→ 브라우저가 `http://localhost:8000`을 엽니다.

**받는 것은 두 종류이고, 하나는 자동이고 하나는 버튼입니다.**

| 무엇 | 어떻게 | 확인 |
|---|---|---|
| 필수 14.7MB | **자동** — 사이트를 열면 알아서 받습니다. 누를 게 없습니다 | `받기` 탭에서 아바타가 움직이면 됨 |
| 전체 124MB | 화면 **오른쪽 위 `📥 오프라인 124.4MB` 버튼**을 누르세요 | `📥 37%`처럼 올라가다 **`📴 준비됨`**(초록)으로 바뀌면 끝 |
| 인식 모델 52MB | `묻기` 탭에서 **카메라를 한 번 켜면** 받습니다 | 손에 점과 선이 찍히면 됨 |

**전체 124MB까지 받아 두세요.** 필수 세트만 받으면 자주 쓰는 낱말만 들어 있어서,
촬영 중에 처음 나오는 낱말에서 **아바타가 조용히 서 있습니다.**

> 화면이 좁으면 버튼에 글자 없이 `📥`만 보입니다. 위치는 같습니다 —
> 맨 위 줄, `받는 중` 오른쪽입니다.

### 2. 카메라 권한 미리 허용 — 1분

`묻기` 탭 → 큰 버튼 → 브라우저가 물으면 **허용**.
한 번 허용해 두면 촬영 중 팝업이 안 뜹니다.

> `localhost`로 열어야 카메라가 켜집니다. `192.168.x.x`로 열면 브라우저가 막습니다.

### 3. 위치 권한 허용 — 1분 ★ 놓치기 쉬움

`묻기` 탭 → **대피소 어디?** 버튼 → 브라우저가 물으면 **허용**.

방향 지도와 거리가 나오면 성공입니다.
**"위치를 켜 주세요"가 뜨면 촬영의 핵심 장면이 날아갑니다.**

> 실내에서는 GPS가 안 잡히고 와이파이 위치로 잡습니다 — 와이파이를 켜 두세요.
> 그래도 안 되면 창가로 가서 한 번 잡아 두면, 그 뒤로는 실내에서도 됩니다.

### 4. 소리 켜기 — 30초

`대화` 탭 → 🏥 병원 → 화면 누르기 → `내 답 카드` → `머리`
스피커에서 "머리"가 나오면 준비 끝입니다.

## ★★ 촬영 직전 (5분)

- [ ] 브라우저 확대 **100%** (`Ctrl+0` / `⌘+0`)
- [ ] 알림·메신저 끄기 (팝업이 화면에 뜹니다)
- [ ] 전체화면 `F11` — 주소창이 사라져 깔끔합니다
- [ ] 방 밝게, **얼굴과 양손이 화면에 다 들어오게** 앉기
- [ ] 배경은 단순하게 (움직이는 것이 없게)

> 수어 인식은 **손이 잘 보여야** 맞습니다. 역광이면 정확도가 크게 떨어집니다.

---

## ★ 찍는 순서 (5분)

각 장면 사이에 2초씩 쉬어 주세요 — 편집이 쉬워집니다.

| # | 화면 | 무엇을 하나 | 시간 |
|---|---|---|---|
| 1 | 랜딩 첫 화면 | 제목만 보여주고 `실측 성과`로 스크롤 | 30초 |
| 2 | 랜딩 `인식` | **카메라 시작 → 수어 → 낱말 → 한국어 → 🔊** | 1분 30초 |
| 3 | 앱 `받기` | 재난문자가 수어로 · `행동요령` 누르기 | 1분 |
| 4 | 앱 `묻기` | 수어로 질문 → 수어로 답 + 방향 지도 | 1분 |
| 5 | 앱 `대화` | 직원 질문 카드 → 수어 / 답 카드 → 소리 | 1분 |

### 2번에서 할 수어 (가장 중요)

**낱말을 하나씩 또렷하게, 사이를 끊어서.**

- `머리` `아프다` → "머리 아파요"
- `병원` `어디` → "병원 어디예요?"

> 이어서 문장으로 하면 아직 못 읽습니다. 낱말 단위입니다.

### 4번에서 할 수어

- `대피` `어디` → 방향·거리·지도가 나옵니다
- `지진` `지금` → 지금 들어온 재난문자를 요약해 수어로
- `방법` `하다` → 행동요령을 수어로

**여기서 비행기 모드를 켜 보세요.** 그대로 답합니다 — "재난 때가 곧 오프라인"이 증명됩니다.

## 안 되면 이렇게 (촬영 중 대처)

| 증상 | 대처 |
|---|---|
| 수어를 했는데 낱말이 안 뜬다 | 손을 화면 가운데로, 조금 크게, 1초 정지 후 다시 |
| 엉뚱한 낱말이 뜬다 | 정상입니다(첫 후보 정확도 74%). `자막 지우기` 누르고 다시 |
| 아바타가 안 움직인다 | 파일을 덜 받은 것입니다. 30초 기다렸다 다시 |
| 카메라가 안 켜진다 | 주소가 `localhost`인지 확인 |
| 소리가 안 나온다 | 크롬·엣지를 쓰세요(사파리는 한국어 음성이 없을 수 있습니다) |

- [ ] 영상에서 **개인정보**(주소·전화번호 입력한 것) 나왔는지 확인
- [ ] `대화` 탭에 앞사람 대화가 남아 있었는지 확인 (5분 지나면 자동으로 지워집니다)
