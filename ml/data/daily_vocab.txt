# 생활 어휘 — 웹 동작 사전에 **빈도와 무관하게** 반드시 실을 낱말.
#
# 왜 필요한가. 웹 사전은 재난문자 말뭉치의 출현 빈도로 상위 N종을 고른다. 그런데 앱이
# 실제로 서는 자리는 병원·약국·관공서·택시·식당 창구다. 실측에서 결과·수술·도장·요금·
# 안전벨트·알레르기 같은 낱말이 **전체 사전(25,627종)에는 있는데 웹 사전에서는 빠져**
# 있었다 — 창구에서 가장 필요한 말들이 재난문자에 안 나온다는 이유로 잘린 것이다.
#
# 여기 적힌 낱말은 표제어(글로스에서 번호를 뗀 형태)로 맞춰 본다. 사전에 없는 낱말은
# export_web_bank가 목록으로 알려 주므로, 그건 데이터가 더 필요하다는 뜻이다.
# 용언은 기본형(-다)으로 적는다 — 활용형은 build_align_dict가 펼친다.
