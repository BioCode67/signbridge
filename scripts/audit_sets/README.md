# 번역 품질 측정용 문장 집합

```bash
node --experimental-strip-types --import ./scripts/ts-register.mjs \
     scripts/audit_translation.mjs scripts/audit_sets/창구대화.json
```

| 파일 | 무엇 | 왜 |
|---|---|---|
| `창구대화.json` | 병원·약국·관공서·택시·식당·은행 58문장 | 사전을 고칠 때 보고 쓴 집합 — **여기 맞춰 튜닝했다** |
| `창구대화_홀드아웃.json` | 같은 자리의 **다른** 37문장 | 튜닝에 쓰지 않았다. 일반화를 재는 정직한 숫자 |
| `행동요령.json` | 행정안전부 국민행동요령 38문장 | 앱이 실제로 재생하는 문장 |
| `일상회화.json` | "안녕하세요·화장실이 어디예요?" 40문장 | **사람이 앱에 처음 넣는 말** |
| (기본값) | `public/data/feed.json` 재난문자 246건 | 실제 수신 문자 |

**홀드아웃을 보고 사전을 고치기 시작하면 그 순간 홀드아웃이 아니다.**
고칠 때는 창구대화.json만 보고, 홀드아웃은 결과 확인에만 쓴다. 튜닝 집합과 홀드아웃의
차이가 벌어지면 시험 문장에 맞춘 것이다.

> 일상회화는 **나중에 추가한 집합**이다. 그 전까지 측정 문장이 전부 격식체 창구·재난문이라,
> "안녕하세요"가 아무것도 내놓지 못하고 "도와주세요"가 '도'로 번역되는 것을 **아무도
> 몰랐다.** 측정 집합이 곧 시야다 — 사용자가 처음 넣을 말부터 넣어 두어야 한다.
