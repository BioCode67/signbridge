차이가 벌어지면 시험 문장에 맞춘 것이다.

### 홀드아웃을 한 번 태워 먹은 기록

`일상회화2.json`은 원래 홀드아웃으로 만든 집합이다. 처음 재니 **85.2%**였고,
거기서 드러난 구멍("해요"가 통째로 빠져 있었다 — 한국어에서 가장 흔한 종결형 중
하나다)을 고쳤다. **그 순간 이 집합은 더 이상 홀드아웃이 아니다.**

그래서 이름을 `일상회화2.json`(튜닝 집합)으로 바꾸고, **새 홀드아웃 50문장**을
따로 만들어 한 번만 쟀다(**87.9%**). 이 파일은 앞으로도 고칠 때 보지 않는다.

고친 것을 숨기지 않기 위해 이 기록을 남긴다 — 숫자보다 **어떻게 잰 숫자인지**가
중요하다.
